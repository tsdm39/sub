## 四、分P：在稿件里标，不另记表

分P 交接靠**稿件内的一行备注**，不靠表、不靠 PR 描述。

**在每个分P 段落的开始处**加一行 `Comment`：

```
Comment: 0,0:00:00.00,0:00:00.00,对白 日语,,0,0,0,,part1（00:00–09:04）
Comment: 0,0:09:04.88,0:09:04.88,对白 日语,,0,0,0,,part2（09:04–15:45）
Comment: 0,0:15:45.49,0:15:45.49,对白 日语,,0,0,0,,part3（15:45–end）
```

**两条硬规矩：**

- **必须用 `Comment:`，不能用 `Dialogue:`** —— 写成 Dialogue 会渲染到画面上
- **起止时间写在文本里**，接手的人一眼看到从哪开始、到哪结束

## 五、各岗红线

### 翻译
- **只填 `对白 中文` 样式**，其余样式一律不碰
- **日语列一个字都不能改**
- 存盘保持 **UTF-8**，编码一变整集报废
- 提交走分支 + PR，**不要直接改主干**

### 轴
- 只改时间码与断句，不动他人样式的文本
- **屏幕字（场面文本）由轴负责** —— 详见下节

### 场面文本 / 特效 / 遮罩
- **归属：轴**（同时计入后期工作的一部分）
- 翻译不碰
- 归属 `场面文本`、`遮罩`、`标题`、`声明` 等样式
- 时长下限：**≥ 12 帧（24fps 下约 0.5 秒）才值得做**
- ⚠️ 但**过下限 ≠ 全做**：0.54 秒内观众只能读 5~6 字，信息密度要另行筛选

### 后期
- 交片进仓库后**知会监制与翻译**（两边都要拿代理对轴 / 试轴）

### 压制
- 交片后**知会监制**，确认 Tracker 与站上发布状态

### 全岗
- 数字、金额、英文词、人名：**当场写进术语表，不要留在脑子里**
- 听不清的标 `⚠️听不清`，**禁止硬猜**（本作后段无 CC，纯听段落必须双人听校）
- **任何备注写 `Comment:`，不要写成 `Dialogue:`**
